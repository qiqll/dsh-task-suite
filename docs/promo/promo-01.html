DSH TASK SUITE · 01

AI 说“做完了”这次终于有人验收

普通 Agent 的自评，和一套机器验收流程的差别。

普通 Agent
自评
WORKER · 最后一条消息“已完成，测试通过 ✅”
  • ×测试真的跑了吗？不知道
  • ×改动越界了吗？没查
  • ×测试被改弱了吗？没审
  • ×能回滚吗？看运气
完成 = 它自己的判断
VS
DSH 任务流水线
机器验收
WORKER · 交付报告 + 证据“T-101 已交付，请验收。”
  • ✓重跑项目测试通过
  • ✓基线 worktree 比对通过
  • ✓测试改弱审计通过
  • ✓越界 / 归属检查通过
通过 → 待验证 → 人确认归档
“完成”不是 worker 的自述，是机器复跑出来的证据。
